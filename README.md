
## Smart sidebar mode

After the user grants overlay permission and taps **Start workspace**, the foreground service creates a narrow handle on the right edge of the screen. The handle and sidebar remain available when the FreeFloat activity is minimized or closed, as long as the foreground service has not been stopped. The sidebar shows tools plus launchable installed apps discovered through Android's normal launcher-intent API. **Edit app shortcuts** expands the list so the user can choose apps such as Telegram, Discord, Chrome, or Phone. Tapping an app launches its normal activity with `FLAG_ACTIVITY_NEW_TASK`; the FreeFloat sidebar stays alive above it.

A normal APK cannot force arbitrary third-party activities into a custom embedded floating window on stock Android. The service makes a best-effort `ActivityOptions.setLaunchBounds` request for Android 7+ devices and OEM builds that support freeform windows, but stock Android phones generally ignore those bounds and open Telegram/Discord normally. Achieving true arbitrary-app floating windows requires Android/OEM freeform-window support or privileged/system capabilities that are not available to an ordinary Play-safe APK. FreeFloat does not use AccessibilityService, screen capture, tap injection, or deceptive embedding.
